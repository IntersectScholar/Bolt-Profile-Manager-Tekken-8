## 🎮 What is Bolt Profile Manager?

Bolt Profile Manager is a **stand‑alone Windows desktop application** that gives Tekken 8 players a powerful, real‑time way to:

- **Create, edit, and switch** character profiles on the fly.
- **Overlay live stats** (damage, health, combo count, etc.) directly onto the game window.
- **Bundle releases** for tournaments, streamers, or personal practice sessions.

All of this is delivered in a sleek, Windows‑native UI that respects your system’s look‑and‑feel.

---

## ✨ Key Features

| Feature | Description |
|--------|-------------|
| **Instant Profile Switching** | Swap load‑outs without leaving the match. |
| **Live Overlay Engine** | Customizable HUD that updates in real time. |
| **Release Bundler** | Package multiple profiles, settings, and overlay presets into a single distributable file. |
| **Windows‑Only Optimizations** | Uses DirectX 12 and Win32 APIs for minimal overhead. |
| **Theme‑able Interface** | Light & dark modes, plus community‑created skins. |
| **Export / Import** | JSON‑based profiles for easy sharing. |

## 🛠️ Installation Walk‑through

1. **System Check** – The installer verifies that you are on Windows 10 / 11 with the required graphics drivers.
2. **User Permissions** – You will be prompted for administrator rights the first time to register a global hot‑key.
3. **Component Selection** – Choose which modules you need (Overlay, Bundler, or both).
4. **Finish** – After installation, a shortcut appears on the desktop and in the Start menu.

> **Tip:** For the smoothest overlay experience, disable any third‑party screen‑recording utility while the manager is active.
